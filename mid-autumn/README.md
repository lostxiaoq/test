# 月满中秋 · 水墨中秋祝福视频

![月满中秋](output/poster.jpg)

**成片：[`output/mid_autumn_ink.mp4`](output/mid_autumn_ink.mp4)**（1920×1080 · 30fps · 43 秒 · H.264 + AAC 立体声）

一幅会自己“画”出来的水墨长卷：一滴墨落在宣纸上，晕开成夜空，留出的空白就是明月（烘云托月）；
远山、松石、渔舟、芦苇依次入画，诗句随毛笔逐字写出，最后盖上朱砂印章。
画面与配乐完全由代码程序化生成，没有使用任何外部图片、视频素材或音频采样。

## 分镜

| 时间 | 画面 | 诗词 |
|---|---|---|
| 0–9.8s | 墨滴落纸 → 墨晕推开，明月显现 → 夜空晕染 → 远山、中山、松石、湖水依次画出，渔舟入画 | 海上生明月，天涯共此时 —— 唐·张九龄《望月怀远》 |
| 9.8–19s | 镜头缓推，雾气流动，月光在水面碎成金鳞，一行归雁横过月轮 | 明月几时有，把酒问青天 —— 宋·苏轼《水调歌头》 |
| 19–28s | 桂枝一笔笔画出，桂花次第绽放，金色桂子随风飘落 | 桂子月中落，天香云外飘 —— 唐·宋之问《灵隐寺》 |
| 28–36s | 夜色渐浓，孔明灯自湖面升起，月华更盛 | 但愿人长久，千里共婵娟 —— 宋·苏轼《水调歌头》 |
| 36–43s | 大字“中秋”落笔，题“花好月圆 阖家安康 · 丙午仲秋”，钤印“人月團圓”，淡出 | |

## 配乐

D 宫五声调式（古筝的传统定弦），72 BPM，散板引子 → 慢板 → 高潮 → 尾声，与画面节点对齐：
墨滴落纸时的低音古筝与编钟、明月显现时的上行刮奏、孔明灯升起时的刮奏与堂鼓、盖印时的鼓与锣。

所有乐器都是合成的：
- **古筝**：Karplus-Strong 弦模型（三角形拨弦激励 + Thiran 全通分数延迟，音准误差 < 1 音分），木质琴身共鸣，揉弦、按滑音、泛音
- **竹笛/箫**：加法合成 + 气声噪声，倚音、滑音、渐起的颤音与连音滑奏
- 弦乐铺底、堂鼓、编钟、锣、风铃、墨滴声、毛笔擦纸声，立体声卷积混响，前瞻限幅

## 水墨渲染

- **宣纸**：纤维、斑驳、颗粒与暗角
- **晕染**：每个元素都由“墨量图 + 到达时间图”描述，逐帧只需按时间阈值显影，墨迹前沿带湿边
- **山石**：分层远近山，披麻皴笔触沿山势放射，苔点、远树，山脚化入云雾
- **笔触**：带飞白的毛笔模型（笔毛在笔画末端和边缘先干）
- **书法**：马善政楷书，笔画先出笔芯再向边缘洇开，另有淡墨晕
- 2.5D 视差镜头（Catmull-Rom 样条），水面倒影与月光碎影，孔明灯辉光

## 复现

```bash
pip install numpy scipy opencv-python-headless pillow imageio-ffmpeg
./fetch_fonts.sh                          # 下载 OFL 开源字体到 fonts/
python3 music.py soundtrack.wav           # 约 25 秒
python3 render.py preview 5 24.5 40.5     # 预览静帧 → preview/
python3 render.py video                   # 全片渲染并合成音轨（4 进程约 6 分钟）→ output/mid_autumn_ink.mp4
```

| 文件 | 内容 |
|---|---|
| `ink.py` | 噪声、宣纸、合成算子、毛笔笔触光栅化 |
| `sky.py` / `backdrop.py` | 墨滴生月、夜空晕染 |
| `mountains.py` / `world.py` | 山体绘制、视差图层、镜头、湖水、云雾 |
| `foreground.py` | 近景山石、古松、芦苇 |
| `osmanthus.py` | 桂枝与桂花 |
| `elements.py` | 渔舟、月光水影、归雁、孔明灯、桂子飘落 |
| `callig.py` | 书法书写动画、朱砂印章 |
| `music.py` | 配乐合成 |
| `render.py` | 时间线与渲染 |
