## 1. 时代时间线（重生节点候选）

| 时间 | 事件 | 可信度 | 对小说的用处 |
|---|---|---|---|
| 1987.11 | 广州开通第一个模拟移动电话网，"大哥大"时代开始 | 🟡 | 老一辈的回忆素材 |
| 1993.9 | 浙江嘉兴开通中国第一个 GSM 数字移动电话网 | 🟢 | 浙江本地情怀梗 |
| 1994 | 中国联通成立 | 🟢 | |
| 2000.4 | 中国移动通信集团成立（移动业务从电信分出） | 🟢 | |
| 2002 | 电信南北拆分，北方十省并入网通 | 🟢 | |
| 2008.5 | 第三次重组：形成移动、电信、联通三家全业务格局（电信收购 C 网，网通并入联通，铁通并入移动） | 🟢 | **重生起点候选①**：重组后人心浮动，岗位洗牌 |
| 2009.1.7 | 发放 3G 牌照：移动拿 TD-SCDMA，联通拿 WCDMA，电信拿 CDMA2000 | 🟢 | TD 终端少、网络弱、要补贴购机，基层很难推 |
| 2009–2012 | 校园开学季大战，充话费送自行车，录取通知书里夹卡 | 🟢 | 热闹的群戏场面 |
| 2012 前后 | 千元智能机、合约机爆发 | 🟡 | 先知型爽点：押注智能机和流量 |
| 2013 起 | 新入网手机号实名制（2016 年底前全面实名） | 🟡 | 补登记的苦活 |
| 2013.12.4 | 发放 4G TD-LTE 牌照（FDD 牌照 2015 年才发） | 🟢 | **重生起点候选②**：TD-LTE 翻身仗，抢建基站 |
| 2012–2015 | 光进铜退，FTTH 光纤入户（铜线接入占比从 49% 降到 21%） | 🟢 | 装维和宽带大战的主战场 |
| 2014.7 | 中国铁塔成立，三家运营商的存量铁塔移交 | 🟢 | 站址资源博弈，共享率从 14% 升到 80% 以上 |
| 2015 | 提速降费成为国家要求 | 🟡 | 收入压力传到基层 |
| 2017–2018 | 取消长途和漫游费，流量不清零，"无限流量"套餐大战 | 🟡 | 资费大战 |
| 2019.6.6 | 发放 5G 牌照（四张，含广电） | 🟢 | **重生起点候选③** |
| 2019.11.27 | 携号转网全国实施 | 🟡 | 存量保卫战：携入、携出、挽留 |
| 2019 前后 | 基层推行网格化运营，网格长、网格承包 | 🟢 | 网格收入涨了，强度也大了 |
| 2020 起 | 5G toB：专网、智慧工厂、智慧矿山、5G+医疗 | 🟡 | 政企逆袭线 |
| 2022.2 | "东数西算"工程启动 | 🟡 | 算力网络 |
| 2023–2026 | 算力网络、AI+、数智化转型；台风保通信常态化（2026 年 7 月"巴威"、8 月"白海豚"） | 🟢 | 当下线、救灾高燃戏 |

## 2. 基层组织与角色图谱（以县级分公司为原型）

> 🟡 下面是对各家运营商的通用抽象，各省差异很大。**小说里一律用虚构公司名**。

```
市分公司
└─ 县（区）分公司 ── 总经理 / 副总（分管市场、网络、政企）
    ├─ 市场部 ─── 渠道管理 · 营业厅（自营厅 / 合作厅 / 社会渠道 / 授权店）
    │              └─ 网格（网格长 / 网格经理，可承包）── 网格内：营业员、直销、装维协同
    ├─ 政企部 ─── 客户经理 · 解决方案经理 · 交付经理（专线 / 物联网 / 云 / ICT 项目）
    ├─ 网络部 ─── 无线 / 传输 / 动力环境 / 网优 · 监控（告警）
    │              └─ 外包：代维公司（基站巡检、退服抢修、油机发电）、装维（计件）
    └─ 综合部 ─── 行政、党建、后勤、车辆
外部：铁塔公司（站址）、设备商（华为 / 中兴等，"局方"是他们对运营商的称呼）、工程队、监理、督导
```

**人物原型池**（每个都带"真实的苦"）

| 角色 | 日常 | 真实的苦（🟢 / 🟡） | 能放的爽点 |
|---|---|---|---|
| 营业员 | 开卡、换卡、办套餐、解释话费，每天被投诉 | 指标压到个人头上，月底冲量 | 一眼看穿客户需求，单日放号破纪录 |
| 网格经理 | 片区经营，扫楼扫街，进村摆摊 | 🟢 网格分三六九等；🟢 完不成任务时**自掏腰包买业务** | 用数据挖出存量金矿，网格从垫底到第一 |
| 装维（外包） | 装宽带、修障，进门要穿鞋套 | 🟢 计件工资；🟢 片区差就"修断线修到傻"；人员流动大 | 技术流：一根皮线救活整栋楼 |
| 代维（外包） | 巡检，退服抢修，油机发电 | 🟢 半夜告警，扛备件爬几个小时山，"主控板换了，第二天又退服"；🟢 多数退服是电源、传输、接头问题 | 精准判断故障根因，台风夜单人保住全镇通信 |
| 政企客户经理 | 拜访决策人，投标，推交付，催回款 | 🟢 一天 50 多个电话；地市业务依赖人脉；考核压力大 | 拿下县里第一个 5G 专网标，智慧工厂落地 |
| 网优 / 无线工程师 | 路测、调参、处理投诉 | 🟡 晚上做割接，白天被投诉 | "改一个参数，全县掉话率降一半" |
| 工程督导（设备商 / 外包） | 盯施工、开站调试 | 🟢 常年出差，被说"没前途、技术含量低" | 草根工程师逆袭成技术专家 |

## 3. 节奏与仪式感（让日常像真的）

- 🟢 **月末出账、割接**：月底出账要加班，网络割接在凌晨做，要通宵。
- 🟡 **周会排名通报**：各网格、各厅按指标排名，有红黑榜，排名靠后的要做检讨。
- 🟡 **月底冲量**：最后三天全员冲指标，网格长到处求人办业务。
- 🟢 **校园开学季**：食堂和宿舍门口摆满展台，有组织的兼职学生，送自行车、行李车。
- 🟢 **抗台保通信**：省、市、县三级驻点待命，油机和抢修车全部下沉一线，跨省调应急电源车和卫星站；挖断的光缆要冒雨熔接。（2026"巴威"台风：浙江投入 4973 人、3160 台油机，据运营商通报）
- 🟡 **重保**：重大活动通信保障（峰会、运动会），专人值守，"零事故"。
- 🟡 **投诉**：最怕工信部申诉、越级投诉；满意度短信"请打 10 分"。
- 🔴 **待补**：具体考核口径、积分怎么算、哪些指标最要命、领导口头禅、食堂和班车、年底评优……

## 4. 行话词库（🟡 需内行核对用法和地方差异）

**市场**：放号（新增开户）、存量（老用户经营）、携入 / 携出（携号转网）、离网率、保有、融合（手机 + 宽带）、合约、终端、渗透率、酬金（给渠道的佣金）、社会渠道、窜货、养卡（红线行为，小说里只能作为反派手段被揭穿）、揽装（揽宽带装机）、冲量、红黑榜
**网络**：退服（基站停止服务）、告警、断站、割接、网优、路测、掉话、弱覆盖、扩容、开站、站址、机房、动环（动力环境）、油机、蓄电池、光交箱、分光器、皮线光缆、光猫、熔接、传输
**政企**：专线、ICT 项目、DICT、标书、废标、集采、交付、回款、解决方案、5G 专网、物联网卡、上云
**设备商**：局方（运营商）、局点、瘫局（局点故障）

## 5. 竞品空白 🟢

搜索起点和番茄，没找到**以运营商基层为主线**的重生文。相近的有《重生 2006：从做智能手机开始》《重生 2010 之移动互联网之父》，都是做手机、做互联网的创业流。
→ "运营商一线 + 重生逆袭"是**少有人写的题材**，而且和咪咕（中国移动旗下）的扶持方向天然契合。

---

## 6. 红线与写作边界

1. **公司名、人物、地名全部虚构**，不点名真实的运营商和领导。咪咕本身就是运营商系，负面描写真实企业尤其不妥。可以写体制里的问题，但要通过具体的人和事表现，避免对行业整体下判断。
2. **违规操作只能作为反派手段被揭穿**，比如养卡、虚假放号、拿用户信息做买卖，不能写成主角的爽点来源。
3. **网络安全**：不写真实网络拓扑、漏洞利用细节。
4. **重生先知的分寸**：主角的爽点要来自"判断正确 + 执行到位 + 能力碾压"，不能靠内幕交易或政策作弊。

## 7. 网上查不到的东西：活人感的真正来源

公开资料能给的是时间线、组织结构、宏观数据和报道里的场面。**真正让读者觉得"作者在里面待过"的细节**，网上查不到，比如：

- 周会上领导那句让全场安静的话
- 网格长月底自掏腰包时的心理账
- 装维进门时客户家的狗、楼道里的味道
- 代维半夜爬山时，手电光里看见什么
- 某个考核指标是怎么被"玩"出来的，又是怎么被堵上的

这部分需要内行提供。见 [素材访谈提纲.md](./素材访谈提纲.md)。
